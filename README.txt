BYBLOS TOWER — FREE AR WEBPAGE

FILES
- index.html: the webpage
- byblos_tower.glb: browser 3D model
- Byblos_Tower.usdz: iPhone AR model

PUBLISH FREE ON GITHUB PAGES
1. Create/sign in to a free GitHub account at github.com.
2. Create a PUBLIC repository called byblos-tower-ar.
3. Choose 'uploading an existing file' / Add file > Upload files.
4. Upload the THREE FILES from this folder (not the zip file).
5. Commit changes.
6. Go to repository Settings > Pages > Build and deployment.
7. Choose Deploy from a branch, branch main, folder /(root), then Save.
8. Wait for the site to be published. The address will normally look like:
   https://YOUR-USERNAME.github.io/byblos-tower-ar/
9. Open the published URL in Safari on an iPhone to test View in AR.
10. Create a QR code pointing to that exact published URL.

IMPORTANT
- The site must be served from HTTPS for reliable AR; GitHub Pages provides this.
- Do not open index.html directly from Windows Explorer for the full experience.
- This example loads the model-viewer web component from a public CDN.
- Keep the model creator's attribution and license visible.
- GitHub Pages repositories are public under this free workflow: uploaded models and source will be publicly accessible.
- Model was downloaded under CC Attribution as shown by Sketchfab; confirm any source-specific terms and keep credit intact.
